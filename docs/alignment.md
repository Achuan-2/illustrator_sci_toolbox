# 对齐对象

左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐使用 Illustrator 的原生对齐命令。“水平与垂直居中”连续调用两个原生居中命令。插件不重新设置选区，不改变 Illustrator 当前的对齐基准，因此保留已指定的关键对象，并遵循原生的选区、画板和预览边界设置。

多选需要对齐的对象后，不按 Shift，再单击其中一个对象，使其成为轮廓加粗的关键对象，然后点击插件中的对齐按钮。关键对象保持原位，其余对象向它对齐。[Adobe 官方操作说明](https://helpx.adobe.com/illustrator/desktop/manage-objects/arrange-objects/align-and-distribute-objects.html)介绍了相同的关键对象选择方式。

原先插件使用整个选区的边界自行计算位移，无法取得原生关键对象状态。现在由 Illustrator 决定对齐基准与边界，不再尝试通过选择顺序推断关键对象，也不在原生命令失败后切换到选区计算。排列分布中的分布与等间距功能继续使用各自现有逻辑。

## 验证

`tests/arrangement.test.ts` 检查各按钮对应的原生命令、执行时保持选区不变、命令失败时不按其他基准移动图稿，并保留分布、交换位置等回归。

在本机 Illustrator 30.8.2 中运行以下脚本：

```powershell
./tests/illustrator-alignment.ps1
```

脚本创建独立临时文档，分别以选区、关键对象和画板为基准，对照六种方向对齐及同时居中的原生结果，共 21 组；检查尺寸保持、关键对象固定，以及原生基准设置和活动文档恢复。关键对象特意使用位于其他对象之间的对象，能够识别退回整个选区边界的错误。

测试设置使用 Illustrator 30.6 新增的切换基准菜单命令，因此原生脚本要求 30.6 及以上；插件本身只调用原有方向对齐命令。旧版 Illustrator 的实际运行、在画布上手动指定关键对象后点击 CEP 按钮的完整 GUI 流程尚未验收。原始原生结果保存在本地 `dist/native-alignment.json`，不纳入版本控制。
